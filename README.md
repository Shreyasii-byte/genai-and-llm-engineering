
# LLM Fundamentals 🤖

## 📌 Overview

This project explores the fundamentals of Large Language Models (LLMs) through practical implementations using Python and the Hugging Face Inference API.

The notebook demonstrates how to interact with LLMs, design effective prompts, generate structured responses, and perform basic response evaluation.

## 🎯 Objectives

- Understand how Large Language Models work.
- Learn different prompt engineering techniques.
- Experiment with zero-shot and few-shot prompting.
- Generate structured JSON outputs using LLMs.
- Build reusable functions for LLM interaction.
- Perform basic evaluation of model responses.

## 🧠 Concepts Covered

| Concept | Description |
|---|---|
| LLMs | Understanding Large Language Models |
| Zero-Shot Prompting | Performing tasks without examples |
| Few-Shot Prompting | Guiding models using examples |
| System Prompts | Defining model behaviour and roles |
| Structured Outputs | Generating machine-readable JSON |
| LLM Evaluation | Testing and analysing model responses |
